# Knegis Skills

A collection of skills developed by Axel and Theo at [Knegis](https://knegis.com).

## Skills

### Consulting tools

Consulting skills live in [`skills/consultingtools/`](skills/consultingtools/).

- **[House PPTX](skills/consultingtools/house-pptx/)** — Create editable, consulting-grade PowerPoint presentations with configurable branding, an HTML-first design workflow, and quality checks. See the [setup guide](skills/consultingtools/house-pptx/GUIDE.md) to get started.

### Engineering tools

- **[Codex Planner](skills/codex-planner/SKILL.md)** — A Claude Code skill that develops an implementation plan with local Codex CLI through independent drafts and mutual critique, then saves the reviewed plan without starting implementation. See the [harness guide](skills/codex-planner/references/harness.md).

- **[Codex Orchestrator](skills/codex-orchestrator/SKILL.md)** — A Claude Code skill for planning engineering tasks and delegating implementation to local Codex CLI workers in isolated Git worktrees, with diff review and verification before integration. Includes a Windows PowerShell harness; see the [setup guide](skills/codex-orchestrator/references/setup.md).
