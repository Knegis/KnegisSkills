# Feedback ledger

Written by `scripts/ledger.py` (sync / note) and by `workroom.py --serve` (register on start, sync after comments and builds).
`decks.txt` = registered deck folders, `ledger.jsonl` = one row per user comment with the agent's category and fix, `summary.md` = per-deck metrics and uncategorised comments.
Ships empty; your first deck reviewed in the live workroom starts it.
