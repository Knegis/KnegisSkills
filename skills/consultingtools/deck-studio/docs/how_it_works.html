deck-studio works in two phases: HTML with you until it is right, then a mechanical translation onto your template
Who does what, and which script does it, from unzipping the skill to the finished .pptx
Once per machine
Phase 1 - design in HTML, with you (most of the time, several rounds)
Phase 2 - translate (fast, uneventful)
You
The agent
The scripts and files
Unzip anywhere, then tell your agent
"Read SKILL.md and run python scripts/setup.py". No admin rights, safe to repeat. Have your company's or client's .pptx template to hand.
Ask for a deck
"Three slides on the Q3 results for the management team." Point at the files that hold the evidence.
Answer two to four batched questions
Which template (yours or plain), which tier, and only what else changes the slide. Routine choices are made for you.
Review in the workroom, comment, repeat
One browser page, every slide full size. Change the thinking here, where it is cheap. As many rounds as it takes.
Say go
Or say "skip the review" at the start if you want it built straight through.
Receive the .pptx
Native shapes and charts on the deck's template, in its font. Later changes go into the HTML and are rebuilt; edits in PowerPoint are overwritten.
Reads SKILL.md
About 7,000 tokens of docs on the default path: SKILL, 00_intake, STYLE, PIPELINE, the corpus manifest. Formats catalogue when needed.
Settles the brief
Message as one sentence per slide, audience, density tier, evidence with file and tab, constraints. Reads the files rather than asking what is knowable.
Chooses the format from the message
Looks at the reference exhibits at that tier for depth, never for the format. Title plus bullets is a defect.
Authors constrained HTML, checks, renders, fixes
1280 x 720 canvas, type in points, palette by role. Loops until typecheck is clean, then opens the workroom.
Builds the deck
Content slides through the pipeline; cover, divider and end slides from the template's own layouts.
Views the PowerPoint render next to the HTML
Mandatory gate: the browser mockup is not evidence. Font audit must print CLEAN. Then hands over, versioned.
setup.py, doctor.py, use_template.py
Packages, a browser, the skill folder, a smoke build. use_template.py puts the deck on your template and derives its palette; --plain for the built-in one.
house.json and reference/
Built-in defaults: plain template, Arial, palette roles, default layout. Thirteen exhibits at T1, T2 and T3 on invented companies.
typecheck.py, render_html.py
Point sizes, colour roles, caps, dashes, canvas use, collisions, overflow, plus anything the translator cannot reproduce. Edge renders the PNG.
workroom.py
Regenerates workroom.html for the deck folder and opens it: every slide in its own frame, zoom, contact-sheet grid.
build_deck.py, chrome_slide.py
Browser geometry -> native shapes and charts -> every typeface patched -> packed and validated on the template.
render_slides.py, fontcheck.py
PowerPoint renders the .pptx to PNGs (COM on Windows; Mac or LibreOffice elsewhere). fontcheck lists every typeface.
